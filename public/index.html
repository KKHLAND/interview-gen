생기부 리뷰와 맞춤 면접 질문을 동시에 만듭니다.

학교생활기록부 처리 안내

  • PDF 원본은 서버로 전송되지 않습니다. 브라우저에서 직접 읽고, 메모리에서만 사용합니다.
  • 6개 영역만 추출합니다. 자율·동아리·진로활동, 교과 성적, 세부능력 및 특기사항, 행동특성 및 종합의견 외의 영역(인적·학적사항, 출결, 수상, 자격증, 학교폭력, 봉사, 독서)은 읽지 않습니다.
  • 머리말·꼬리말을 버립니다. 각 페이지 하단의 성명·반·번호·학교명·출력 정보는 좌표 기준으로 제외합니다.
  • 2중 마스킹. 주민번호·전화번호·이메일·주소·학교명 패턴은 브라우저와 서버에서 한 번 더 가립니다.
  • 저장하지 않습니다. 서버는 요청을 Gemini API에 전달만 하고 기록하지 않습니다. 새로고침하면 모든 결과가 사라집니다.
  • Gemini 무료 등급 API 키를 쓰면 Google이 입력을 서비스 개선에 활용할 수 있습니다. 실제 학생 자료에는 유료(결제) 등급 키를 권장합니다.

Gemini API 키 설정

이 앱은 Google Gemini로 질문과 답변을 만듭니다. 키는 무료로 1분이면 발급받을 수 있어요.

  1. 1
    Google AI Studio 열기

    Google 계정으로 로그인합니다. 처음이면 이용약관에 동의하세요.

    aistudio.google.com/apikey 열기
  2. 2
    ‘API 키 만들기(Create API key)’ 클릭

    프로젝트를 고르라는 창이 뜨면 기본 프로젝트를 선택하거나 새로 만듭니다.

  3. 3
    만들어진 키를 복사해 아래에 붙여넣기

    요즘 발급되는 키는 AQ.으로 시작합니다. (예전 키는 AIza로 시작)

도움말 · 비용과 보안
  • 요금 — 무료 등급으로도 사용할 수 있지만 분당·일일 사용량 제한이 있습니다. 한도 초과(429) 오류가 잦으면 사용량 한도를 확인하거나 AI Studio에서 결제를 연결하세요. 요금 안내
  • 학생 자료 — 무료 등급은 입력이 Google 서비스 개선에 쓰일 수 있습니다. 실제 학생 생기부에는 결제(유료) 등급 키를 권장합니다.
  • 키 보관 — 키는 이 브라우저에만 저장되고, 요청할 때 이 PC의 로컬 서버를 거쳐 Google로만 전달됩니다. 공용 PC에서는 ‘이번 탭에서만 사용’을 고르세요.
  • 키가 새면 — AI Studio에서 해당 키를 삭제하고 새로 만드세요.
