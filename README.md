# 생기부 면접 Lab

학교생활기록부 PDF(또는 이 앱에서 저장한 엑셀·MD·JSON)와 지원 대학·학과를 넣으면, **입학사정관 시점**에서 생기부 리뷰, 맞춤 면접 질문, 모범 답변과 꼬리질문을 만들고 모의 면접까지 진행하는 웹앱입니다. AI 모델은 Google Gemini(`gemini-flash-latest`)를 씁니다.

## 실행

```bash
npm install
npm start                # http://localhost:5178
```

브라우저에서 오른쪽 위 **‘API 키 설정’** 버튼을 누르면 발급 안내와 연결 테스트가 나옵니다.

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 Google 계정으로 로그인합니다.
2. ‘API 키 만들기(Create API key)’를 누릅니다.
3. 발급된 키(요즘 키는 `AQ.`로 시작하고, 이전 키는 `AIza`로 시작)를 붙여넣고 **테스트 후 저장**을 누릅니다.

- 키는 브라우저에만 저장됩니다(‘이 브라우저에 기억’ 또는 ‘이번 탭에서만’ 중 선택). 요청할 때만 로컬 서버를 거쳐 Google로 전달됩니다.
- 서버 관리자는 `.env`의 `GEMINI_API_KEY`로 공용 키를 넣어 둘 수도 있습니다(`.env.example` 참고). 브라우저에 입력한 키가 있으면 그 키가 우선합니다.
- Node.js 20 이상이 필요합니다. 외부 의존성은 `@google/genai`, `pdfjs-dist` 두 개입니다.
- `.env`의 `GEMINI_MODEL`을 바꾸면 다른 Gemini 모델을 쓸 수 있습니다.

## 기능

| 탭 | 내용 | 참고한 서비스 |
|---|---|---|
| 추출 데이터 | 6개 영역 파싱 결과, 학기별 성적표, **MD·JSON 편집기와 MD·JSON·엑셀 저장**, **AI로 전송될 텍스트 미리보기·직접 수정** | Qupid AI의 학생부 처리 안내 |
| 생기부 리뷰 | 학생 유형, 총평, 전공 적합도, 8대 평가요소 레이더, 영역별 평가, 강점과 약점, 학기별 등급 추이, 면접 전략, **PDF·한글·Word·TXT 내보내기** | Qupid AI의 6개 영역 리뷰 |
| 면접 질문 | 15·30·45문항, 평가요소와 영역 필터, 검색, 근거 원문, 출제 의도, 답변 포인트, 모범 답변, 꼬리질문(2·3단계), 문항별 **재생성·프롬프트 수정**, 보관, **PDF·한글(hwpx)·Word(docx)·TXT** 내보내기·복사 | AI Studio 면접 생성기(8대 요소, 꼬리질문), Qupid(재생성·수정·PDF) |
| 실전 연습 | 문항 세트 선택, 제한시간 타이머, **음성 답변**(Chrome), 답변별 AI 채점·개선 답변·후속 질문, 결과 요약, **결과(질문·내 답변·채점·다듬은 답변) PDF·한글·Word·TXT 내보내기** | 몬스터T(실전형 응시 → 결과 진단) |
| 대학 정보 | Google 검색 그라운딩으로 인재상, 평가요소, 면접 방식, 교육과정을 가져오고 출처 링크 제공 | AI Studio 면접 생성기 |

## 업로드 형식

| 형식 | 확장자 | 처리 방식 |
|---|---|---|
| PDF | `.pdf` | NEIS 출력 생기부를 좌표 기반으로 파싱해 6개 영역만 추출 |
| 엑셀 | `.xlsx` `.xlsm` `.xls` `.csv` | 시트 `창체`·`교과성적`·`세특`·`행특`(또는 같은 열 제목)을 6개 영역으로 읽음. CSV는 UTF-8·EUC-KR 모두 지원 |
| Markdown | `.md` `.markdown` `.txt` | `## 영역` / `### 항목` 구조(이 앱에서 저장한 형식)를 6개 영역으로 읽음 |
| JSON | `.json` | `creative`·`grades`·`seteuk`·`behavior` 배열(이 앱에서 저장한 형식)을 6개 영역으로 읽음 |

- **PDF → MD·JSON 변환:** '추출 데이터' 탭의 **파일로 저장 · 편집** 카드에서 Markdown 또는 JSON으로 바꿔 보며 직접 고치고, `편집 내용 적용`으로 화면과 AI 전송 텍스트에 반영합니다. `.md`·`.json`·`.xlsx`로 저장한 파일은 다음에 그대로 다시 올릴 수 있습니다.
- 이 앱 형식이 아닌 엑셀·MD·JSON은 내용 전체를 **자유 텍스트**로 읽어 AI 전송 텍스트로 씁니다. 이때는 영역 필터링이 적용되지 않으니 전송 전에 확인하세요(패턴 마스킹은 적용됩니다).
- 엑셀 처리는 [SheetJS](https://sheetjs.com)를 엑셀 파일을 다룰 때만 CDN에서 불러옵니다.
- 변환 점검: `npm run test:formats` (PDF 경로를 주면 실제 생기부로 왕복 점검)

## 결과물 내보내기

면접 질문 · 생기부 리뷰 · 모의 면접 결과를 모두 내보낼 수 있습니다. 파일은 브라우저에서 바로 만들어지고 서버로 가지 않습니다.

- **PDF·인쇄** — A4 인쇄용 양식으로 인쇄 창을 엽니다. 'PDF로 저장'을 고르면 PDF가 됩니다.
- **한글(.hwpx)** — 한글 2014 이상에서 열립니다. 빈 양식(`public/hwpx-template.js`, `scripts/make-hwpx-template.py`로 생성)에 제목·소제목·굵게 서식을 넣어 만듭니다.
- **Word(.docx)** — 제목·제목 1·제목 2 스타일이 적용되어 탐색 창에서 목차로 보입니다.
- **TXT** — 메모장 등에서 바로 열리는 텍스트(UTF-8)입니다.
- 면접 질문은 ★보관한 문항이 있으면 그 문항만, 없으면 전체를 내보냅니다.

## 개인정보 보호 설계

1. **파일은 서버로 올라가지 않습니다.** PDF는 pdf.js로, 엑셀·MD·JSON은 브라우저에서 직접 읽습니다.
2. **6개 영역만 읽습니다.** 창의적 체험활동(자율·동아리·진로), 교과 성적, 세부능력 및 특기사항, 행동특성 및 종합의견만 읽습니다. 인적·학적사항, 출결, 수상, 자격증, 학교폭력, 봉사, 독서는 섹션 단위로 건너뜁니다.
3. **머리말과 꼬리말을 좌표로 버립니다.** 각 페이지 하단의 성명·반·번호·학교명·출력 정보는 텍스트를 읽기 전에 위치 기준으로 제외합니다.
4. **2중 마스킹을 합니다.** 주민번호·전화·이메일·주소·학교명 패턴을 브라우저(`parser.js`)와 서버(`server.mjs`)에서 한 번씩 더 가립니다.
5. **전송 전에 확인할 수 있습니다.** Gemini로 보내는 것은 '추출 데이터' 탭의 텍스트뿐이며, 사용자가 직접 지우거나 고칠 수 있습니다.
6. **저장하지 않습니다.** 서버는 요청 본문을 저장하거나 로그로 남기지 않습니다. 결과는 탭 메모리에만 있습니다. 파일명에도 이름이 들어가는 경우가 많아 화면에 표시하지 않습니다.

> ⚠️ Gemini **무료 등급** 키를 쓰면 Google이 입력을 서비스 개선에 활용할 수 있습니다. 실제 학생 자료를 다룰 때는 결제(유료) 등급 키를 쓰세요.

## 파서 점검

```bash
node test/parse-sample.mjs <생기부.pdf> 학생이름,학교명,담임이름
```

추출 결과를 요약해 보여 주고, 지정한 금지어(이름 등)가 결과에 하나라도 남아 있으면 실패로 종료합니다.

## 구조

```
server.mjs          정적 파일 + Gemini 프록시 (/api/review, /api/questions[스트리밍], /api/question, /api/feedback, /api/university)
public/parser.js    좌표 기반 생기부 파서 (브라우저/Node 공용)
public/formats.js   추출 데이터 ↔ MD·JSON·엑셀 변환 (브라우저/Node 공용)
public/exporters.js 결과물 → 인쇄 HTML·TXT·docx·hwpx (zip 직접 생성)
public/hwpx-template.js  hwpx 빈 양식 (scripts/make-hwpx-template.py로 생성)
public/app.js       화면 로직
public/app.css      디자인 (라이트/다크, 반응형, 인쇄용)
test/               파서 점검 스크립트
```
