# 생기부 면접 Lab

학교생활기록부 PDF와 지원 대학·학과를 넣으면, **입학사정관 시점**에서 생기부 리뷰, 맞춤 면접 질문, 모범 답변과 꼬리질문을 만들고 모의 면접까지 진행하는 웹앱입니다. AI 모델은 Google Gemini(`gemini-flash-latest`)를 씁니다.

## 실행

```bash
npm install
npm start                # http://localhost:5178
```

브라우저에서 오른쪽 위 **‘API 키 설정’** 버튼을 누르면 발급 안내와 연결 테스트가 나옵니다.

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 Google 계정으로 로그인합니다.
2. ‘API 키 만들기(Create API key)’를 누릅니다.
3. 발급된 키(요즘 키는 `AQ.`로 시작하고, 이전 키는 `AIza`로 시작)를 붙여넣고 **테스트 후 저장**을 누릅니다.

- 키는 브라우저에만 저장됩니다(‘이 브라우저에 기억’ 또는 ‘이번 탭에서만’ 중 선택). 요청할 때만 로컬 서버를 거쳐 Google로 전달됩니다.
- 서버 관리자는 `.env`의 `GEMINI_API_KEY`로 공용 키를 넣어 둘 수도 있습니다(`.env.example` 참고). 브라우저에 입력한 키가 있으면 그 키가 우선합니다.
- Node.js 20 이상이 필요합니다. 외부 의존성은 `@google/genai`, `pdfjs-dist` 두 개입니다.
- `.env`의 `GEMINI_MODEL`을 바꾸면 다른 Gemini 모델을 쓸 수 있습니다.

## 기능

| 탭 | 내용 | 참고한 서비스 |
|---|---|---|
| 추출 데이터 | 6개 영역 파싱 결과, 학기별 성적표, **AI로 전송될 텍스트 미리보기·직접 수정** | Qupid AI의 학생부 처리 안내 |
| 생기부 리뷰 | 학생 유형, 총평, 전공 적합도, 8대 평가요소 레이더, 영역별 평가, 강점과 약점, 학기별 등급 추이, 면접 전략 | Qupid AI의 6개 영역 리뷰 |
| 면접 질문 | 15·30·45문항, 평가요소와 영역 필터, 검색, 근거 원문, 출제 의도, 답변 포인트, 모범 답변, 꼬리질문(2·3단계), 문항별 **재생성·프롬프트 수정**, 보관, PDF·TXT·복사 | AI Studio 면접 생성기(8대 요소, 꼬리질문), Qupid(재생성·수정·PDF) |
| 실전 연습 | 문항 세트 선택, 제한시간 타이머, **음성 답변**(Chrome), 답변별 AI 채점·개선 답변·후속 질문, 결과 요약 | 몬스터T(실전형 응시 → 결과 진단) |
| 대학 정보 | Google 검색 그라운딩으로 인재상, 평가요소, 면접 방식, 교육과정을 가져오고 출처 링크 제공 | AI Studio 면접 생성기 |

## 개인정보 보호 설계

1. **PDF는 서버로 올라가지 않습니다.** pdf.js로 브라우저에서 직접 파싱합니다.
2. **6개 영역만 읽습니다.** 창의적 체험활동(자율·동아리·진로), 교과 성적, 세부능력 및 특기사항, 행동특성 및 종합의견만 읽습니다. 인적·학적사항, 출결, 수상, 자격증, 학교폭력, 봉사, 독서는 섹션 단위로 건너뜁니다.
3. **머리말과 꼬리말을 좌표로 버립니다.** 각 페이지 하단의 성명·반·번호·학교명·출력 정보는 텍스트를 읽기 전에 위치 기준으로 제외합니다.
4. **2중 마스킹을 합니다.** 주민번호·전화·이메일·주소·학교명 패턴을 브라우저(`parser.js`)와 서버(`server.mjs`)에서 한 번씩 더 가립니다.
5. **전송 전에 확인할 수 있습니다.** Gemini로 보내는 것은 '추출 데이터' 탭의 텍스트뿐이며, 사용자가 직접 지우거나 고칠 수 있습니다.
6. **저장하지 않습니다.** 서버는 요청 본문을 저장하거나 로그로 남기지 않습니다. 결과는 탭 메모리에만 있습니다. 파일명에도 이름이 들어가는 경우가 많아 화면에 표시하지 않습니다.

> ⚠️ Gemini **무료 등급** 키를 쓰면 Google이 입력을 서비스 개선에 활용할 수 있습니다. 실제 학생 자료를 다룰 때는 결제(유료) 등급 키를 쓰세요.

## 파서 점검

```bash
node test/parse-sample.mjs <생기부.pdf> 학생이름,학교명,담임이름
```

추출 결과를 요약해 보여 주고, 지정한 금지어(이름 등)가 결과에 하나라도 남아 있으면 실패로 종료합니다.

## 구조

```
server.mjs          정적 파일 + Gemini 프록시 (/api/review, /api/questions[스트리밍], /api/question, /api/feedback, /api/university)
public/parser.js    좌표 기반 생기부 파서 (브라우저/Node 공용)
public/app.js       화면 로직
public/app.css      디자인 (라이트/다크, 반응형, 인쇄용)
test/               파서 점검 스크립트
```
